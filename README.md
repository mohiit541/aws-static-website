
# AWS Static Website Hosting

## Project Overview
Deployed a static website using Amazon S3.

## Technologies Used
- Amazon Web Services (AWS)
- Amazon S3
- IAM
- Git
- GitHub

## Key Tasks
- Created and configured an S3 bucket.
- Uploaded HTML website files.
- Enabled static website hosting.
- Configured public read access for website assets.
- Validated website accessibility using the S3 website endpoint.
- Managed project source code using Git and GitHub.
